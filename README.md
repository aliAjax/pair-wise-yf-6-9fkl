## 危废清运交接（第二版）

完工时按危废白名单（废电池、废铅酸蓄电池、油漆桶、荧光灯管、废矿物油、废有机溶剂）
登记类别、数量、暂存点；普通垃圾不得入危废账，本次无危废可直接完工。

业务规则：

- **整次拒绝**：任一明细超出暂存点对该类别的余量（或暂存点不接收该类别），
  整次移交拒绝，不占用容量，事项保持「处理中」，拒绝记录追加台账。
- **签收一致**：清运签收逐项核对，实收数量必须与移交完全一致并填写凭证；
  缺凭证或数量不符，自动转入「异常复核」，事项冻结归档、容量继续占用。
- **补说明放行**：补处置说明只释放当前事项，移交/签收历史明细不改写，放行后容量释放。
- **本地存档**：归档随事项实时同步（异常冻结不入档、删除/改状态联动撤档）；
  台账只追加。筛选条件与全部数据经 localStorage 持久化，刷新保留。

代码按三个业务文件拆分，不依赖框架或新增库：

| 文件 | 职责 |
| --- | --- |
| `src/rules.js` | 危废白名单、余量校验、签收一致性、异常放行、视图状态/筛选（纯函数） |
| `src/storage.js` | localStorage 存档、暂存点种子、台账只追加、归档同步 |
| `src/ui.js` | 渲染与交互，调用规则层判定、存储层持久化 |

`src/main.js` 仅负责组装三个文件。
