# 家庭维修事项

端口规划：`5114`

```bash
npm install
npm run dev
```

第一版闭环：记录维修问题、按状态查看、更新处理状态、统计未完成预计费用，支持照片链接并使用 localStorage 保存数据。

## 第二版：危废清运交接

完工时登记废电池、油漆桶等危废的类别、数量与暂存点：

- 仅危废白名单可入账，普通垃圾不得入账；确无危废可“直接完工”。
- 暂存点按类别核算余量；任一类别余量不足则整次拒绝，事项保持处理中。
- 签收数量必须与移交一致且必须有清运凭证；缺凭证或数量不符转入异常复核并冻结归档（冻结期间仍占暂存点余量）。
- 补处置说明后仅释放当前事项；原移交/签收记录与历史流水不改写，只追加。
- 状态筛选、余量统计均随本地存档保存，刷新后保留。

代码按业务拆分为三个文件，无新增依赖：

- `src/rules.js`：危废类别、余量计算、移交/签收/复核全部业务规则（纯逻辑）。
- `src/storage.js`：localStorage 存档读写、旧版数据迁移、暂存点种子数据。
- `src/ui.js`：筛选、余量面板、事项卡片与三个交接弹窗的渲染和事件。
